# 📚 Bookly

## Présentation

Bookly est une application web permettant à un utilisateur
de gérer sa bibliothèque personnelle.

## Objectif

L'utilisateur pourra :
- consulter ses livres ;
- ajouter des livres ;
- consulter les détails d'un livre ;
- gérer sa bibliothèque personnelle.

## Technologies actuelles

- PHP
- Symfony
- Twig
- HTML

## Technologies prévues

- MySQL
- Doctrine
- CSS
- JavaScript
- Git / GitHub
